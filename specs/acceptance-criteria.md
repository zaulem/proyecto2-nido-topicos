# Criterios de aceptación

- **AC-01:** Al abrir la aplicación se muestran al menos cuatro espacios con precio y capacidad.
- **AC-02:** Con datos válidos, el usuario obtiene una confirmación con identificador.
- **AC-03:** Con correo inválido, la reserva no se crea y se muestra un error.
- **AC-04:** Dos reservas solapadas del mismo espacio y fecha no pueden coexistir.
- **AC-05:** Reservas contiguas son válidas.
- **AC-06:** El total cambia al modificar duración o equipo adicional.
- **AC-07:** Una cancelación con correo ajeno no modifica la reserva.
- **AC-08:** El recorrido funciona en viewport móvil.
