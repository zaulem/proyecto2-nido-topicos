# Estrategia de pruebas

`npm test` ejecuta la suite nativa de Node.

- Validación de usuario y correo.
- Solapamiento y franjas contiguas.
- Regla crítica de no doble reserva.
- Reservas simultáneas en espacios distintos.
- Cálculo de extras audiovisuales.
- Cancelación autorizada por correo.

La prueba `rechaza doble reserva del mismo espacio y franja` cubre explícitamente la restricción obligatoria del PDF.
