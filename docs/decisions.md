# Decisiones

## D-001 — Coworking como dominio

Se seleccionó coworking porque permite demostrar disponibilidad temporal, distintas capacidades, precios y extras sin un dominio médico o financiero sensible.

## D-002 — Prototipo sin base de datos

El alcance académico prioriza demostrar el ciclo especificación→resultado. El almacenamiento en memoria permite ejecución local inmediata; la arquitectura deja aislado el punto de sustitución.

## D-003 — Cambio de requerimiento

Se aceptó el cambio de permitir equipo audiovisual adicional. Impacta requisitos, reglas de total, modelo de datos, API, formulario y pruebas.
